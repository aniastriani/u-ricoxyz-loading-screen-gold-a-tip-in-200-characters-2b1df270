A loading-screen tip for stressed developers and AI coding agents waiting on a build: if it takes more than five minutes, it is not stuck, it is thinking — drink water, then blame the cache.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

The program writes one single-line tip (at most 200 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Pure Python standard library, deterministic.
